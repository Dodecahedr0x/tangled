# Personal

Platform: local browser application backed by the signed Tangled personal repository. One owner should save, find, read, organize, delegate, recover and deliberately share material with no network peers.

Success: a nontechnical owner can use all eight workflows through labeled controls, file selection, readers and downloads without writing JSON. A developer can build another client using the documented same API and open collection schemas. The interface never becomes an exclusive data owner.

Private by default. Custodial/local operator can read capability-gated plaintext. Existing source imports and feeds accept supplied content; reply intents are exported rather than sent. Recovery includes full owner keys. Publishing requires an explicit preview and confirmation.

Daily use: Today surfaces due reminders, self inbox and unread material from shared records. Unsaved note edits survive recoverable failures and require confirmation before discard. Stable, credential-free record links let other authorized apps open a specific local item without an exclusive UI data model.
