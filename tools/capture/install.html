Keep a page for later.

Drag this button to your browser’s bookmarks bar:

Save to Tangled

On a page you want to save, click the bookmark. It downloads tangled-capture.json with the page URL, title, visible article text, and any selected passage.

From the Tangled repository, import the downloaded file:

cargo run -p tangled-personal -- --data ./personal capture < ~/Downloads/tangled-capture.json

The file stays on your computer. The helper makes no server requests, reads no cookies or browser storage, and does not send data to a service. Review the JSON before importing if the page contains sensitive material.

Page policies may block bookmarklets or downloads. You can instead supply the same fields in a JSON file manually. Article capture uses the first article or main element, with visible body text as a fallback; it is a plain-text snapshot, limited to 1,048,576 characters.
