# reed-core

Domain crate. No Dioxus. Depends on `tangled` only. Copy Loomed identity/outbox/replica/sync/handle — not chat/MLS/HPKE/receipts/circles.

Parent adds workspace member `apps/reed/core` so `-p reed-core` resolves.

## Interfaces (pin from tree/1.md + A21/A22)

Types, `ReedError`, `ReedKeys`/`FileKeyStore`, `Replica`, `Outbox`, `Sync`, `PostApi`, graph/social, `search`/`mentions`/`parse_peer`/`resolve_handle` — exact signatures in `.agent/tree/1.md`.

- Max 4 media, any mix image/video (`ReedError::MediaLimit`). Honor `describe.maxBlob` (`MediaTooLarge`).
- Quote: `pub.tangled.post` envelope `ref` = original CID, no body `reply`.
- Reply: body `reply` = parent record CID.
- `pub.reed.*` via `sys.schema` Last-ts-wins; schemas in `apps/reed/core/schemas/`.
- Delete: no `delete_record` on `KnotClient` — last-ts-wins put, replica `deleted: true`.
- `Sync::poll_once`: `get_head`/`get_repo` for me + each follow `subject` (optional per-follow knot URL).
- `edit_text` copies stored body and replaces only text (keeps media record CIDs).
- `Outbox.drain`: `put_blob` then `put_record`. Tests: `MockKnot::hosting(did)`.
