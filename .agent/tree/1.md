# Reed

Dioxus Twitter clone. Domain in `reed-core` (no dioxus). UI in `reed`. Uses `crates/tangled`. MockKnot in tests; HTTP `KnotClient` in prod. Public posts only — no Loomed circles/MLS/HPKE.

Do not edit `crates/tangled/**` unless a missing export blocks a pinned signature — then add the smallest pub use and log it.
Do not edit `apps/loomed/**`.

## Collections

| collection | rkey | body | vis |
|---|---|---|---|
| `pub.tangled.post` | TID | `text` (≤32 KiB), optional `langs`, `reply` (parent record CID), `media` (CIDs) | `public` |
| `pub.tangled.media` | TID | `blob`, `mime`, optional `alt` | `public` |
| `tangled.graph.follow` | DID-safe (`:`→`.`) of subject | `v`, `subject`, optional `knot` | `public` |
| `tangled.graph.block` | DID-safe of subject | spec block body | `public` |
| `pub.reed.like` | CID-safe of target | `{ "target": "<post cid>" }` | `public` |
| `pub.reed.boost` | CID-safe of target | `{ "target": "<post cid>" }` | `public` |
| `pub.reed.profile` | `self` | `{ "displayName": string, "bio": string, "avatar": cid? }` | `public` |
| `pub.reed.mute` | DID-safe of subject | `{ "subject": "<did>" }` | `public` |

Publish `sys.schema` for each `pub.reed.*` on first use (Last-ts-wins). Schema JSON lives in `apps/reed/core/schemas/`.

Reply: body `reply` set. Quote: envelope `ref` = original CID, no body `reply` (A22). Boost: `pub.reed.boost`. Media per post: max 4, any mix of image/video (A21).

## Pinned replica / outbox / sync

```rust
pub struct Replica { /* local records + heads + blob bytes */ }
impl Replica {
    pub fn open(dir: &std::path::Path) -> Result<Self>;
    pub fn home(&self, me: &str) -> Vec<TimelineItem>; // follows + own, newest ts_us; hide mute/block/deleted
    pub fn discover(&self, me: &str) -> Vec<TimelineItem>; // public posts in replica, same filters
    pub fn profile_posts(&self, did: &str) -> Vec<Post>;
    pub fn thread(&self, id: &PostId) -> Vec<Post>; // root then replies by ts_us
    pub fn post(&self, id: &PostId) -> Option<Post>;
    pub fn profile(&self, did: &str) -> Option<Profile>;
    pub fn apply_record(&mut self, bytes: &[u8]) -> Result<()>;
}

pub struct Outbox { /* pending putRecord/putBlob */ }
impl Outbox {
    pub fn enqueue_record(&mut self, record: serde_json::Value) -> Result<()>;
    pub fn enqueue_blob(&mut self, bytes: Vec<u8>) -> Result<()>;
    pub fn drain(&mut self, client: &tangled::KnotClient) -> impl std::future::Future<Output = Result<usize>>;
}

pub struct Sync {
    pub knot: KnotUrl,
    pub client: tangled::KnotClient,
}
impl Sync {
    pub fn http(knot: KnotUrl) -> Result<Self>;
    pub fn mock(engine: std::sync::Arc<std::sync::Mutex<tangled::MockKnot>>) -> Self;
    pub fn probe(&self) -> impl std::future::Future<Output = Result<()>>; // describe
    pub fn poll_once(&mut self, replica: &mut Replica, keys: &ReedKeys) -> impl std::future::Future<Output = Result<()>>;
}
```

`Sync::http` uses `KnotClient::http`. `poll_once`: `describe` for `maxBlob`; `get_head`/`get_repo` for me + each follow `subject` (optional per-follow `knot` URL). Discover uses public posts already in the replica plus any extra hosted DIDs the test/UI passes through replica known-authors. No WebSocket in v1. Public `get_repo` only.

Writes: `Outbox.drain` → `put_blob` then `put_record`. UI drain does not SIWS. Tests: `MockKnot::hosting(did)`.

```rust
pub struct PostApi { pub keys: ReedKeys }
impl PostApi {
    pub fn compose_text(&self, replica: &mut Replica, outbox: &mut Outbox, text: &str, reply_to: Option<&PostId>, quote_of: Option<&PostId>) -> Result<PostId>;
    pub fn compose_with_media(&self, replica: &mut Replica, outbox: &mut Outbox, text: &str, blobs: &[(Vec<u8>, String /* mime */, Option<String> /* alt */)], reply_to: Option<&PostId>, quote_of: Option<&PostId>) -> Result<PostId>;

    pub fn delete(&self, replica: &mut Replica, outbox: &mut Outbox, id: &PostId) -> Result<()>;
}
```

`compose_*` signs `pub.tangled.post` via `tangled::record::sign_json_record`, `vis: "public"`. Media: `putBlob` + `pub.tangled.media` CID in `media`. Honor `maxBlob`. Media count: max 4 any mix (A21). Quote: envelope `ref` = original CID, no body `reply` (A22). Delete: tombstone/hide in replica (`deleted: true`); enqueue spec delete if `KnotClient` exposes it, else last-ts-wins put of same rkey with empty display handled as deleted in replica.

## Pinned UI

CSS: bg `#12141a`, sidebar `#0c0e12`, copper `#c47a4a`, text `#e6e8ee`, muted `#9aa3ad`, radius 2px, Fira Sans (copy font files from Loomed assets, new `apps/reed/assets/`). `notify-rust` on desktop for local OS notifications.
